## 🎯 Executive Summary

This implementation plan provides a complete roadmap for developing a Modbus BMS simulator that enables testing and development of the GA Modbus Python App without physical hardware. The simulator creates virtual COM ports, simulates an 8S LiFePO4 battery management system, and provides an interactive CLI interface using Python's Rich library.

### Key Objectives
- ✅ **Virtual COM Port Management** - Cross-platform virtual serial communication
- ✅ **Modbus Protocol Simulation** - RTU/ASCII protocol compliance with realistic timing
- ✅ **8S LiFePO4 BMS Simulation** - Physics-based battery behavior modeling
- ✅ **Rich CLI Interface** - Professional interactive terminal interface
- ✅ **Configurable Test Scenarios** - Multiple testing modes and fault injection
- ✅ **GA Modbus App Integration** - Seamless drop-in hardware replacement

## 📊 BMS Register Mapping Specification

### Core Register Layout

```python
# Cell Voltages (mV resolution)
CELL_VOLTAGES = {
    0x1000: "cell_voltage_1",    # Range: 2500-3650 mV
    0x1001: "cell_voltage_2",    # Individual cell voltages
    0x1002: "cell_voltage_3",    # for 8S LiFePO4 pack
    0x1003: "cell_voltage_4",
    0x1004: "cell_voltage_5",
    0x1005: "cell_voltage_6",
    0x1006: "cell_voltage_7",
    0x1007: "cell_voltage_8",
}

# Pack Measurements
PACK_DATA = {
    0x2000: "pack_voltage",      # Total pack voltage (mV): 20.0V-29.2V
    0x2001: "pack_current",      # Pack current (mA, signed): ±200A
    0x2002: "state_of_charge",   # SOC percentage (0.1% resolution)
    0x2003: "remaining_capacity" # Remaining Ah capacity
}

# Temperature Sensors (°C × 10 resolution)
TEMPERATURES = {
    0x3000: "temp_sensor_1",     # Range: -40°C to +85°C
    0x3001: "temp_sensor_2",     # Cell temperature monitoring
    0x3002: "temp_sensor_3",     # for thermal management
    0x3003: "temp_sensor_4",
}

# Protection & Status
PROTECTION = {
    0x4000: "protection_status", # Protection status flags
    0x4001: "alarm_status",      # Alarm condition register
    0x4002: "fault_status",      # Fault condition register
}
```

| Function | Code | Description | Implementation |

| Read Input Registers | 0x04 | Real-time sensor data | Primary function |

## 🔧 Installation and Usage

### Quick Start
```bash
# Clone the repository
git clone https://github.com/your-org/modbus-bms-simulator.git
cd modbus-bms-simulator

# Install dependencies
pip install -r requirements.txt

# Setup virtual COM ports (platform-specific)
python scripts/setup_virtual_ports.py

# Run the simulator
python -m modbus_bms_simulator --config config/default.yaml
```

### Configuration Example
```yaml
# config/default.yaml
simulator:
  com_port: "COM3"        # Virtual COM port to create
  baud_rate: 9600         # Serial communication settings
  modbus_address: 1       # Modbus device address
  update_rate: 10         # Hz - simulation update frequency

battery:
  chemistry: "LiFePO4"    # Battery chemistry
  cells_in_series: 8      # Number of cells
  nominal_voltage: 3.2    # Nominal cell voltage
  capacity_ah: 100        # Battery capacity

scenarios:
  default: "normal_operation"  # Default test scenario
  
cli:
  refresh_rate: 10        # Hz - CLI update frequency
  theme: "dark"           # CLI color theme
```

### CLI Interface Usage
```bash
# Start with specific scenario
python -m modbus_bms_simulator --scenario charging

# Enable debug mode
python -m modbus_bms_simulator --debug --verbose

# Custom configuration
python -m modbus_bms_simulator --config custom_config.yaml
```
