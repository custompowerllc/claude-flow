  🎯 SPARC Research Methodology

  Claude-Flow includes SPARC (Specification, Pseudocode, Architecture, Refinement, Completion) modes specifically for research:

  Research Mode

  npx claude-flow@alpha sparc run researcher "investigate AI adoption trends in enterprise"

  Analysis Mode

  npx claude-flow@alpha sparc run analyst "analyze productivity metrics across remote teams"

  🐝 Multi-Agent Research Swarms

  For complex research projects, Claude-Flow can deploy multiple specialized agents:

  # Complex research project
  npx claude-flow@alpha hive-mind spawn "comprehensive market research for electric vehicle charging infrastructure" --agents
  "researcher,analyst,planner,documenter"

  This creates a research team where:
  - Researcher: Gathers information from multiple sources
  - Analyst: Processes and interprets data
  - Planner: Structures findings and recommendations
  - Documenter: Creates comprehensive reports

  💾 Knowledge Management

  Claude-Flow's memory system is perfect for research:

  # Store research findings
  npx claude-flow@alpha memory store "ai-trends-2024" "key findings from research"

  # Query previous research
  npx claude-flow@alpha memory query "market analysis" --category research

  # Export research database
  npx claude-flow@alpha memory export research-knowledge.json
